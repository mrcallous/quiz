# 六套PMP模拟题核验与16天提分计划

分析日期：2026-11-19。考试：2026-12-05，中国大陆线下。

## 先给结论

按所附题库答案逐题核算，1080题共700对、380错，正确率64.81%。目前有一定通过基础，但不能据此判断稳过，更不能给出可信的80%或90%通过概率。主要训练杠杆是需求变更、质量、风险、治理生命周期中的动作选择与先后顺序；并非所有敏捷题或所有长题都弱。

12月5日是中国大陆新版PMP正式开考日。官方公布180题、240分钟，人员33%、过程41%、业务环境26%；要覆盖AI、可持续发展、业务价值与情景/图形题。来源：[PMI中国官方升级说明](https://www.pmichina.org/certification/project-management-pmp/new-exam)。本报告的10类学习标签不能直接当作这3个官方领域的成绩。

PMI以岗位胜任标准和心理测量方法确定通过标准，官方手册没有提供可直接套用到这些模拟卷的固定正确率换算。这里的75%只作后续训练目标。来源：[PMI认证手册，第17页](https://www.pmi.org/-/media/pmi/documents/public/pdf/certifications/generic-certification-handbook.pdf)。

## 2. 重复题核验与记忆影响

先比对题干的中英文规范化文本，再用中文三字片段相似度与双语题干/选项加权相似度寻找变式，人工复核候选。仅ID不同不能证明题目不同；同一长案例下不同子问题也不能算重复。

完全相同的规范化题干为0组；确认4组近重复变式，其中跨卷3组、冲刺卷内1组，共8次出现。另有“市场份额被颠覆”的题目情境相近，但问题与选项有变化，保守未计入重复。语义检索仍可能漏掉差异较大的改写，这些数字限于本次可检出的重复。

今后每次练习先标“首见/见过但不记答案/记得答案”，同时记录用时与信心，才能真正分开知识掌握与记忆收益。

2. **质量与持续改进：77题错37题，错误率48.05%，为最高。** 强化一95把鱼骨图与帕累托混用；冲刺1在核查既有QA活动前先做返工影响分析。要按题目要解决的问题选工具，区分确定重点、找根因、看稳定性、做验收。
3. **治理与生命周期：114题错48题。** 重点是启动时利用组织知识、收尾与移交、合规/治理决策、价值变化后的再评估。不能把“先识别风险”“先开会”当万能答案。
4. **风险、资源采购、进度成本：分别错38/96、40/107、28/73。** 集中补管理储备/应急储备、风险/问题/残余风险、弱矩阵资源权限、合同风险归属、赶工/快速跟进、参数/类比/三点估算，以及工具与文档用途。

沟通类正确102/141=72.34%，商业价值49/68=72.06%，团队104/145=71.72%，相对较好，但都仍有明显失分。不能因为商业价值较好而忽略新版业务环境：后者不止商业价值，还涉及战略、组织变革、合规等任务。题库已有AI、可持续和案例题，说明不能简单判定它全部沿用旧版；但也无法由这些题证明官方权重覆盖充分。

|工具文档边界混淆|77|21.45%|

最常见的前三类共270/359=75.21%：

- **措施未击中问题（112次）**：强化一18，个体疑似缺培训却选集体重审DoD；模考一50，资深员工不满微观管理却选加强导师式交流，未解决自主空间问题。训练时必须说出“题目当前到底缺什么”。
- **行动顺序跳步（81次）**：强化一4，交付物被质疑，选记录并向管理层报告，遗漏需求跟踪与检查；冲刺1，先返工影响分析而未核查QA证据。每题注明已知事实、缺失信息、下一项获授权动作。
- **工具文档边界混淆（77次）**：强化一95，识别关键缺陷类别选鱼骨而非帕累托；冲刺54，跟踪业务收益选规划时评审DoD，未区分完成质量与业务收益。
- **角色与权限错置（37次）**：模考二55与强化二138，两次都以团队检查愿景一致性替代PO对产品规格的决策；强化一80，弱矩阵下资源优先级冲突应找职能经理协商，不能只在执行团队之间协调。
- **概念或计算混淆（32次）**：模考三120，未知风险对应管理储备，不能用已定义的应急措施替代；强化一119，参数估算与类比估算区分不足。

不要把以上总结压成固定口诀。事实尚未清楚时常需分析，但应对措施已获批且触发条件满足时可能应立即执行；紧急安全/法律要求可能要先控制损害并按规定上报。角色权限、授权边界和题目问“首先/接下来/本应/最有效”都要读全。

## 7. 11月20日至12月4日的具体计划

默认普通日每天90～120分钟，另外安排两次完整240分钟模拟。若某天无法连续4小时，把整套练习移到最近可行日期；日常分段练习不能替代至少一次完整时长验证。今晚只需看这份结论并建立复盘卡，不必再做整卷。

路径选择：继续每天刷整卷容易重复熟题且挤压复盘；只背旧错题难验证迁移；建议以专题首见题修正决策规则，再用两次完整首见卷检查迁移。旧题只用于解释为什么错，新题才用于检验能不能用。

|12/5|按准考证安排参加线下考试。|练习目标是约210分钟完成作答、保留约30分钟核对；按案例长度和现场规则调整，不把每题时间设成硬上限。|

每天90～120分钟可分为：15分钟回忆规则，35～45分钟首见题，30～40分钟解释错题与低信心答对题，10～20分钟做间隔复测。多选按选项逐一写“题干证据/角色权限/是否当前动作”，再检查选择数量。

错题卡统一5项：①题目究竟问什么；②关键事实与限制；③我选的动作解决了什么、漏了什么；④正确选项为什么在当前情境更合适；⑤触发条件变化时答案何时会变。避免抄整段解析或记答案字母。

11/20起按四条决策顺序练习：
1. 确认项目阶段、开发方式、题目时间指向和已有事实。
2. 识别当前缺口是信息、分析、决策授权、执行还是反馈。
3. 确认谁能决定、谁需参与，有无现成批准的计划和阈值。
4. 选择最直接解决当前缺口的动作，再核对价值、合规与必要程序。

计算/工具卡优先内容：SV=EV−PV（以0为界）、CV=EV−AC；SPI=EV/PV、CPI=EV/AC（以1为界）；三角估算(O+M+P)/3与题目指定PERT时的(O+4M+P)/6；赶工与快速跟进；参数与类比估算；帕累托与鱼骨/控制图；DoR与DoD；评审与回顾；管理储备与应急储备。不要把进度SV直接解读成延期天数，也不要从指标单独跳到未经分析的纠偏动作。

## 8. 正式考试风险评估与训练门槛

当前判断：**有通过基础，稳定性和迁移证据不足，仍有明显风险。**

有利证据：六卷无空答；模考三与强化二接近69%；案例题33/38；若干近重复题出现后一次答对。主要风险：整体64.81%，冲刺60%，多选44.44%，重复出现的权限误判，以及质量/治理/风险/变更的跨卷失分。新版业务环境占26%，不能按旧版8%的学习投入处理。

没有对这些卷的难度等值、历届考生模拟—正式结果数据，也没有真实首见题和用时标记。老师所说“偏难”只能作为背景，不能推导正式考试会多对多少题。不能给出有统计意义的通过概率。

可衡量的提分目标：从六卷平均每180题116.7对，争取提高到约129～135对（71.7%～75%）。在359道可诊断错题中，前三类模式有270次；若后续同类训练避免其中约25%～40%，换算到180题大约可少错11～18题。这是训练情景和努力目标，不是正式考试分数预测，也不能把不同专题的收益重复相加。

考前观察门槛（分析者提出，非PMI及格线）：
- 两次180题、240分钟、首见、闭卷且匹配新版的独立模拟，尽量都达到75%（135对）；题库难度不同，仍需结合细项判断。
- 需求变更、质量、风险、治理等核心专题在足够首见题中至少70%；多选累计至少30道首见样本、正确率争取≥70%。这些样本可包含完整模拟中的题，不必额外堆量。
- 后续60题限时抽测连续两次≥45对，且能解释相似干扰项为什么不适合当前情境；已见题不能用来满足此门槛。
- 完整240分钟内能完成并留出填写/核对时间；低信心答对题纳入复盘，避免把猜对当掌握。

达到上述目标会提供更积极的准备证据，仍不构成通过保证。如果首见模拟仍多次低于65%，或靠熟题达到高分，考前风险仍明显，应继续按错误模式补短板；是否存在可调整考期的渠道以官方当前安排为准，本报告不假设还能缓考。

你最该带进考场的变化，是能解释“为什么此时由这个角色采取这个动作”，并能识别题库过度绝对化的解释。
